PRIVACY POLICY

개인정보처리방침

JusTim LENOVO Backup은 개인 서버의 암호화 백업을 private Backblaze B2 bucket에 저장하기 위한 비공개 운영 도구입니다.

시행일: 2026년 9월 18일 · 운영자: 임동한

1. 적용 범위와 목적

이 방침은 JusTim LENOVO Backup이 Backblaze B2에 개인 서버 백업 파일을 저장·확인·정리하는 과정에 적용됩니다. 도구는 외부 고객에게 제공되지 않으며 운영자 본인만 사용합니다.

2. 처리하는 데이터

  • B2 인증 정보: LENOVO 전용 bucket에 한정된 Application Key
  • 도구가 생성한 암호화 백업 파일(.cms)과 무결성 확인 파일(.sha256)
  • 업로드 성공 시각, 파일명, 파일 크기, 실행 결과 등 최소 운영 기록

백업 원문과 서버 비밀 설정은 B2에 전송되기 전에 암호화됩니다. 복호화 개인키는 B2 및 LENOVO 서버에 저장하지 않고 운영자의 Mac에만 보관합니다.

3. B2 접근 권한

도구는 justdoim-lenovo-backup private bucket에만 Read and Write 권한을 가진 Application Key를 사용합니다. Master Application Key는 LENOVO에 저장하지 않으며 다른 bucket의 파일이나 이름을 조회하지 않습니다.

4. 이용 및 공유

백업 데이터는 생성·암호화·업로드·무결성 확인·복원 검증·삭제라는 명시된 기능에만 사용합니다. 광고, 마케팅, 사용자 프로파일링, 데이터 판매에 사용하지 않으며 법적 의무가 있는 경우를 제외하고 제3자와 공유하지 않습니다.

5. 저장 위치와 보유 기간

  • Application Key: 운영자 LENOVO 서버의 권한 제한 설정 파일에 저장
  • 암호화 백업: private B2 bucket에 저장하며 운영자가 직접 삭제하거나 정한 lifecycle 정책에 따라 삭제
  • LENOVO의 암호화 임시본: 정상 업로드 후 최대 2일 보관
  • 실행 로그: 장애 확인과 복구 검증에 필요한 기간만 보관

6. 보안 조치

  • B2 전송 전에 공개키 기반 CMS 암호화와 AES-256 적용
  • B2 bucket의 기본 SSE-B2 암호화 적용
  • 복호화 개인키와 암호는 Mac에만 분리 보관
  • Application Key를 전용 bucket에 한정하고 설정 파일 권한을 제한
  • Tailscale 전용망을 이용한 서버 관리
  • 정기 checksum 확인과 실제 복원 검증

7. 삭제와 권한 철회

운영자는 B2의 justdoim-lenovo-backup bucket에서 백업을 직접 삭제할 수 있습니다. Backblaze 계정에서 전용 Application Key를 언제든지 삭제할 수 있으며, key를 삭제하면 이후 자동 업로드는 중단됩니다.

8. 외부 저장소

Backblaze B2는 암호화된 파일의 off-device 저장소로만 사용합니다. B2에는 복호화 개인키와 평문 백업을 전송하지 않으며 bucket은 공개하지 않습니다.
