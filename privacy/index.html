PRIVACY POLICY

개인정보처리방침

JusTim LENOVO Backup은 개인 서버의 암호화 백업을 본인의 Google Drive에 저장하기 위한 비공개 운영 도구입니다.

시행일: 2026년 9월 18일 · 운영자: 임동한

1. 적용 범위와 목적

이 방침은 JusTim LENOVO Backup이 Google Drive API를 이용해 개인 서버 백업 파일을 저장·확인·정리하는 과정에 적용됩니다. 도구는 외부 고객에게 제공되지 않으며 운영자가 승인한 본인 Google 계정만 사용합니다.

2. 처리하는 데이터

  • Google OAuth 인증 정보: access token과 refresh token
  • 도구가 생성한 암호화 백업 파일(.cms)과 무결성 확인 파일(.sha256)
  • 업로드 성공 시각, 파일명, 파일 크기, 실행 결과 등 최소 운영 기록

백업 원문과 서버 비밀 설정은 Google Drive에 전송되기 전에 암호화됩니다. 복호화 개인키는 Google Drive 및 LENOVO 서버에 저장하지 않고 운영자의 Mac에만 보관합니다.

3. Google API 권한

도구는 https://www.googleapis.com/auth/drive.file 범위만 요청합니다. 이 범위는 도구가 생성했거나 사용자가 도구에 명시적으로 제공한 특정 파일을 만들고 확인·수정·삭제하는 데 사용됩니다. 다른 Drive 파일을 임의로 탐색하거나 처리하지 않습니다.

4. 이용 및 공유

Google 사용자 데이터는 백업 생성·업로드·무결성 확인·삭제라는 명시된 기능에만 사용합니다. 광고, 마케팅, 사용자 프로파일링, 데이터 판매에 사용하지 않으며 법적 의무가 있는 경우를 제외하고 제3자와 공유하지 않습니다.

5. 저장 위치와 보유 기간

  • OAuth 인증 정보: 운영자 LENOVO 서버의 권한 제한 설정 파일에 저장
  • 암호화 백업: 운영자의 Google Drive에 저장하며 운영자가 직접 삭제하거나 정한 보존 정책에 따라 삭제
  • LENOVO의 암호화 임시본: 정상 업로드 후 최대 2일 보관
  • 실행 로그: 장애 확인과 복구 검증에 필요한 기간만 보관

6. 보안 조치

  • Google Drive 전송 전에 공개키 기반 CMS 암호화와 AES-256 적용
  • 복호화 개인키와 암호는 Mac에만 분리 보관
  • OAuth 설정 파일의 운영체제 접근 권한 제한
  • Tailscale 전용망을 이용한 서버 관리
  • 정기 checksum 확인과 실제 복원 검증

7. 삭제와 권한 철회

운영자는 Google Drive의 LENOVO-Encrypted-Backups 폴더에서 백업을 직접 삭제할 수 있습니다. Google 계정의 서드 파티 연결 관리 화면에서 언제든지 앱 권한을 철회할 수 있습니다. 권한을 철회하면 이후 자동 업로드는 중단됩니다.

8. Google API 정책 준수

Google API에서 받은 정보의 사용과 전송은 Google API Services User Data Policy와 Limited Use 요구사항을 준수합니다. 자세한 내용은 Google API Services User Data Policy에서 확인할 수 있습니다.
