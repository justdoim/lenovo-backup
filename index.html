JusTim LENOVO Backup

개인 서버의 백업을 암호화하여 private Backblaze B2 bucket에 보관하는 비공개 운영 도구입니다.

개인용 · 비상업적 · 외부 사용자에게 제공하지 않음

무엇을 하나요?

1. 백업

개인 LENOVO 서버의 데이터베이스, 파일 저장소와 복구에 필요한 설정을 백업합니다.

2. 암호화

B2에 보내기 전에 공개키 기반 암호화로 잠급니다. 복호화 개인키는 Mac에만 보관합니다.

3. 제한 업로드

전용 private bucket에만 접근하는 제한 Application Key로 암호문과 checksum만 관리합니다.

데이터 사용 경계

  • Application Key는 LENOVO 전용 private bucket 하나에만 접근합니다.
  • B2에는 복호화할 수 없는 암호문과 checksum만 저장합니다.
  • 제3자를 위한 공개 서비스가 아니며 운영자 본인만 사용합니다.
  • 별도의 분석 도구, 광고 쿠키, 사용자 추적 기능을 사용하지 않습니다.
